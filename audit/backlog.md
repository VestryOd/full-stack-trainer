# Backlog — что править и в каком порядке

Составлено из фазы 1 (покрытие) и фазы 2 (читабельность, все 62 зоны). Аналитики посещаемости нет,
поэтому порядок собран из трёх факторов: **корректность важнее языка**, затем **темы, к которым вы
готовитесь к интервью** (Node, PostgreSQL, React, System Design, MongoDB, Prisma), затем **вес
дефектов** по оценкам аудита.

Правки языка делаются командой `/fix-readability <путь>` — одна зона за сессию.

## Блок 3. Промпты, куда добавить «следуй content/STYLE.md»

Сами промпты не менял — только перечисляю. Все они генерируют или правят контент, поэтому строка
`Follow content/STYLE.md — it is the readability contract for this project.` нужна в каждом.

**В репозитории:**

| Файл | Что генерирует | Куда добавить |
|---|---|---|
| `scripts/PROMPT_2_CONTENT.md` | TASK A — вычитка русских статей, TASK B — **перевод статей на английский**, TASK C/D/E — вопросы, задачи, quiz | Новым пунктом 7 в `## CRITICAL QUALITY RULES`. Отдельно в TASK B — правила §8 стайлгайда: английскую версию **разбивать заново**, а не переводить структуру русского предложения (это первоисточник паттерна «EN тяжелее RU») |
| `scripts/generate-content.js` | Вопросы через Anthropic API | В шаблон промпта внутри скрипта (системного промпта там нет, только `role: 'user'`) |
| `scripts/generate-quiz.js` | Quiz | Туда же, **плюс** правила §9 стайлгайда: перемешивать `correctIndex`, уравнивать длины вариантов, не ссылаться на позиции, обязательные фенсы, сверка со статьями и банком темы |
| `scripts/generate-tasks.js` | Задачи с решениями | В шаблон промпта внутри скрипта |

Не нужно — контент не генерируют: `PROMPT_1_SCAFFOLD.md` (каркас проекта),
`PROMPT_3_PAGES.md` (страницы), `PROMPT_4_DEPLOY.md` (деплой),
`PROMPT_5_I18N_FIXES.md` (файл переводов интерфейса, цвета, favicon, адаптивность).

**Вне репозитория** (проверьте у себя, аудит их не видит):

- **промпт генерации статей топиков** — тот, которым сделаны `content/topics/*/ru/*.md`. В репозитории
  его нет: `PROMPT_2_CONTENT.md` только проверяет уже существующие русские статьи (TASK A) и
  переводит их (TASK B). Это самый важный промпт для стайлгайда — статьи составляют 40% контента;
- **промпт генерации глав курсов** — `content/courses/*` появились позже всех `PROMPT_*` файлов;
- любые сохранённые в Claude Code / IDE шаблоны и слэш-команды для добавления топика или банка;
- `CLAUDE.md` проекта, если появится: сослаться на `content/STYLE.md` как на контракт.

## Как двигаться

1. Блок 0 целиком — одним проходом по корректности, начиная с 0.1 и 0.10.
2. Шаблоны генерации (конец блока 0 + блок 3) — чтобы новый контент не воспроизводил дефекты.
3. Дальше по волнам блока 1: `/fix-readability <зона>`, одна зона за сессию.
4. Блок 2 — по мере появления времени; пункты 1-4 закрывают самые частые вопросы интервью.
